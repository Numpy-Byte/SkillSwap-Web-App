SkillSwap — Campus Asset & Knowledge Exchange

A static, responsive front-end prototype for the ten SkillSwap interfaces. It uses plain HTML, CSS, and JavaScript, so there is no build step or package installation.

## Run locally

Open `index.html` in a modern browser. The app starts on the sign-in screen. Use the navigation and action buttons to move through the screens and preview the basic flows.

## Screens

1. Login / Sign Up
2. Home / Dashboard
3. Browse Assets & Skills
4. Search & Filter Results
5. Item / Skill Details
6. Request Item / Skill Session
7. Create Listing
8. My Requests / Transactions
9. Transaction Details / Status
10. Profile & Credit Balance

## Project files

- `index.html` contains the screen markup and shared application shell.
- `style.css` contains the visual system, reusable UI styles, and responsive layouts.
- `app.js` contains the screen navigation and demo interactions.
- `assets/skillswap-logo.png` is the supplied SkillSwap logo.
